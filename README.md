# Resume Skill Extractor

**Resume Skill Extractor** is a web application that allows users to upload their resume files (PDF, DOCX, or TXT) and automatically extracts relevant skills using a predefined list of technical and soft skills. It’s a helpful tool for job seekers, recruiters, and developers working on resume analysis or HR automation.

### Frontend:
- React.js
- Tailwind CSS

- File Saver.js

### Backend:
- Flask (Python)
- Flask-CORS
- pdfminer.six
- docx2txt

## 🚀 Features

- Upload resume in **PDF, DOCX, or TXT** format.
- Extracts **technical** and **soft skills** from the resume content.
- Displays the detected skills visually.
- Option to **download** the extracted skills as a `.txt` file.
- Beautiful animations and transitions for better UX.
